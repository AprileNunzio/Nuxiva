# Support

Nuxiva is a self-hosted, local-first assistant. Pick the channel that fits your question.

| Need | Where |
| :--- | :--- |
| Installation, configuration, operations | The [README](README.md) and `nuxivactl status`, `nuxivactl logs` and `nuxivactl repair` on the host |
| Reproducible bug | A [bug report](https://github.com/AprileNunzio/Nuxiva/issues/new?template=bug_report.md) with version (`nuxivactl version`), platform and relevant logs, with personal data removed |
| Feature idea | A [feature request](https://github.com/AprileNunzio/Nuxiva/issues/new?template=feature_request.md) describing the problem before the solution |
| Security vulnerability | Privately, as described in [SECURITY.md](SECURITY.md). Never in a public issue |
| Conduct concern | The address in the [Code of Conduct](CODE_OF_CONDUCT.md) |
| Commercial license | See section 3 of the [LICENSE](LICENSE) |

Before opening an issue, search existing ones. Never paste tokens, vault contents, face or voice data, or private addresses.
